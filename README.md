# 🔍 GitHub Finder profile

Aplicação web desenvolvida com [Vite](https://vitejs.dev/), [TypeScript](https://www.typescriptlang.org/) e [Tailwind CSS](https://tailwindcss.com/), que consome a API pública do GitHub para exibir informações de qualquer usuário.

## 🚀 Tecnologias Utilizadas

- [Vite](https://vitejs.dev/) — Bundler rápido para front-end moderno
- [React](https://reactjs.org/) — Biblioteca JavaScript para construir UIs
- [TypeScript](https://www.typescriptlang.org/) — Superset do JavaScript com tipagem
- [Tailwind CSS](https://tailwindcss.com/) — Framework utilitário para estilização rápida
- [GitHub API](https://docs.github.com/pt/rest) — Para busca de dados dos usuários

## ⚙️ Instalação e Uso

Clone o repositório:

```bash
git clone https://github.com/seu-usuario/seu-repositorio.git
cd seu-repositorio
```

## Instale as dependências:
```bash
npm install
```

## Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

## Abra no navegador:
```bash
http://localhost:5173
```

## 🧠 Funcionalidades

- Busca por nome de usuário do GitHub
- Exibe:
  - Foto de perfil
  - Nome e bio
  - Número de repositórios públicos
  - Número de seguidores e seguindo
  - Localização, blog/site e Twitter (se disponíveis)
- Design responsivo e leve
